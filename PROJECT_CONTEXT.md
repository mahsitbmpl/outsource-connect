```

 │  pinned) → 128-d descriptor → match         └─ calls API with session token
 │  against cached descriptors (IndexedDB)
 ├─ decides IN/OUT from own cached last punch
 ├─ queue (IndexedDB, UUID per punch)
 └─ HMAC-signed requests (device token)
                 │  HTTPS POST, Content-Type text/plain (no CORS preflight)
                 ▼
 Google Apps Script web app (doPost router, LockService on writes, input validation)
 ├─ Sheets: Settings, Rules, Departments, Companies, Rates, Staff, FaceData, Punches_YYYY,

 │          Users, Sessions, AuditLog, Heartbeats, EmailLog, MonthLocks
 ├─ Drive: /photos/YYYY-MM, /unrecognised, /backups, /packs/YYYY-MM
 └─ Triggers: process punches (5 min), heartbeat watchdog (5 min), morning/evening email,
              nightly close, weekly backup, 1st-of-month draft pack, yearly punches roll-over
```
- **Shared rule engine:** one plain-JS file `shared/rules.js` used by the server (Apps Script V8), the console (what-if/preview) and the kiosk (OUT-screen hours). Tests run in Node against the same file.
- **Device token:** generated by Admin in the console, entered once on the tablet via a setup screen, stored in tablet storage only (never in the public repo). Requests are signed (HMAC-SHA256 of body + timestamp + nonce); server rejects stale timestamps and reused nonces. Token can be revoked/rotated from the console.
- **Clock:** every API response returns server time; tablet keeps an offset; each punch stores device time, corrected time and server-received time.
- **Free GitHub Pages needs a public repo** → code is public, data and secrets never are.

## 5. Rule engine — defaults and confirmed reading
Settings (versioned with effective dates; same for all departments; per-department override possible later):
| Key | Default |
|---|---|
| boundaries | 08:00, 20:00 (duty = 12 h) |
| grace_after_boundary_min | 10 |
| late_start | **Owner decision 20-Nov-2026:** IN later than grace → start rounds UP to the next full hour (08:12 → 09:00). Any start not snapped to a boundary also rounds up (22:20 → 23:00, 05:30 → 06:00). No automatic grace on later hours. |
| late_grace_review | If IN falls within grace (10 min) after a later full hour (e.g. 09:05, 10:08), the bill uses the strict hours (09:05 → from 10:00) and a **"Late arrival" exception** is raised; Ops manager chooses Keep strict / Give grace (from 09:00) / Override. The extra hour stays out of the bill until decided. Month lock blocked while open. |
| early_snap_window_min | 120 |
| leave_early | exact minutes |
| extra_after_last_boundary | whole hours + minutes: <30→0, 30–44→0.5, 45–59→1.0 |
| split | first 8 → "8 Hrs", next 4 → "4 Hrs", rest → "Double Duty"; duties = hours/12 |
| duty_date | date of start |
| shift_tag | Day if IN 04:00–13:59, else Night (editable) |
| duplicate_window_min | 3 |
| open_amber_h / open_red_h | 13 / 24 |
| over12_needs_approval | on |
| short_duty_review | < 12 h |

Algorithm (prototype passed all 9 required cases on 20-Nov-2026):
1. Start = nearest boundary B if IN ∈ [B − 120 min, B + grace]; else actual IN.
2. Find boundaries strictly after start and ≤ OUT. If none → hours = exact (OUT − start).
3. Else hours = (last such boundary − start) + extraRound(OUT − last boundary).

Required cases: 08:05→20:32 = 12.5 | 08:00→20:29 = 12.0 | 08:00→20:44 = 12.5 | 08:00→20:45 = 13.0 | 08:00→06:00(+1) = 22.0 | 08:00→01:00(+1) = 17.0 (8/4/5) | 22:00→08:30(+1) = 10.5 | 11:00→17:00(+1) = 30.0 | ~~08:12→20:00 = 11.8~~ → **11.0** under the owner's late rule.
New expected (confirmed 20-Nov-2026): 08:12→20:40 = 11.5 | 08:10→20:00 = 12.0 | 08:59→20:00 = 11.0 | 09:05→20:00 = 10.0 + Late-arrival exception (grace → 11.0) | 22:20→08:30(+1) = 9.5 | 05:30→20:00 = 14.0 | 08:00→15:20 = 7.33 | 19:55→08:10(+1) = 12.0.

## 6. Billing logic (from Sample_Sheet.xlsx, HK Oct-26)
- Per designation: Total hrs = 8 Hrs + 4 Hrs + Double Duty; Net hrs = Total − Deduction hrs; Duties = Net/12.
- Amount = Duties × rate per duty (Supervisor line, Staff line). Gross = sum.
- Total = Gross − Penalties; GST 18% on Total; Net = Total + GST. (GST is applied after penalties.)
- Sample tabs: Bill Details (Bill block, HK Details block, Deduction Duties details, Penalty Remarks numbered), Summary Sheet (per-day 8hrs/4hrs/Double/Total/Duties/Double-duty names), 8 Hours Duty, 4 Hours Duty, Double Duty (grids: SR, NAME, SUP/HK, days 1–31, TOTAL HOUR; "A" = absent).
- Findings in the sample: supervisor rate 806.45 = 25,000 ÷ 31; Summary sheet Total Hours/Total Duties omit 31-Oct (264 hrs) so it shows 691.55 duties vs 711.55 in Details (bill used Details, so bill is right); Double Duty contains 1.3 and 3.3 (looks like h.mm notation, summed as decimals); amounts unrounded; deduction 24 h shown as 16 (8hrs) + 8 (4hrs).
- The sample contains real staff names: never copy into repo, tests or previews.
