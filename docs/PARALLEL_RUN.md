# One-month parallel run plan

Run the new system **and** the paper register side by side for one full calendar month. Go live with the system alone only after the sign-off at the end.

## Before the month starts (by the last week of the previous month)

- [ ] Every active staff member is in **Staff**, with the correct department, designation and company.
- [ ] Every face is enrolled, and each person has done one test punch.
- [ ] Rate cards for every department and designation are entered, with the right effective date.
- [ ] Penalties and deductions will be entered in the system **and** written in the register, as usual.
- [ ] The Ops manager and HK, SS and SC supervisors have read the Ops Manager manual.
- [ ] Emails arrive (morning, evening), and the tablet alert works (unplug the Wi-Fi for 20 minutes).

## Every day

| Who | What |
|---|---|
| Staff | Punch on the tablet **and** sign the register, as usual. |
| Supervisors | Note anyone who could not punch, with the reason. |
| Ops manager | Clear Exceptions (morning). Note every case where the system and the register disagree, and why. |

## Every week (Monday)

1. Type last week's register into the **Parallel run check** template (Employee ID, Date, Hours).
2. Upload it on **Parallel run check**. Write the match % in the table below.
3. For each difference, decide whose figure is right:

| Cause | Action |
|---|---|
| Forgot to punch, or the face was not recognised | Fix it on Exceptions (the register is right). |
| Register mistake | Correct the register (the system is right). |
| Rule question, for example late-arrival rounding | Check **Duties → How?**. If the rule itself is wrong, write it down for IT. |
| System error | Send the date, the person, the register figure and the system figure to IT. |

**Target:** at least 98% match after the fixes by week 3, and no unexplained differences.

## At month end

1. Make the manual bill from the register, the old way.
2. In the system: clear Exceptions, open **Month-end pack → View bill**, download the Excel pack and the PDF, and **lock** the month.
3. Compare, for each department:

| Department | Manual net payable | System net payable | Difference | Explained? |

4. A difference is acceptable only when its cause is known and agreed. For example, the system rounds amounts to paise, or a register mistake.
