## Findings and changes made in Phase 6

1. Unchanged rows are no longer written back: a blank cell read back as "" or empty was taken as a change, so every 5-minute run rewrote all open-duty rows. Now only changed rows are written, and only the block between the first and last changed row.
2. Large tabs are read by date range: a job reads the date column first and then only the rows it needs (a month 2 years back no longer reads the whole year).
3. New tabs lose their empty columns, so the cell limit is spent on data only.
4. Each January, log rows and exceptions older than *dataKeepYears* move to "OutSource Connect archive YYYY" (checked before removal); punch and duty tabs of old years move the same way.
5. The month-end screens read only the month's exceptions, and the dashboard only today's punches.
6. *dataKeepYears* default lowered from 3 to 2: 3 past years + the current year would use about 75 % of the cell limit.
7. Exceptions are looked up by date when marked resolved (before, an exception older than about 5,000 rows could be missed).
